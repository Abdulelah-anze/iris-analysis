# Iris Dataset Analysis

## Project Overview

This project analyzes the Iris dataset using Python and Pandas.

The project includes data exploration, filtering, descriptive statistics, grouping, data visualization, and exporting analysis results.

## Technologies Used

- Python
- uv
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The project uses the Iris dataset.

The dataset contains 150 rows and 5 columns:

- sepal_length
- sepal_width
- petal_length
- petal_width
- species

The dataset contains three Iris species:

- setosa
- versicolor
- virginica

## Summary of Findings

The Iris dataset contains 150 rows and 5 columns, with three species: setosa, versicolor, and virginica.

There are no missing values in the dataset. The average sepal length is approximately 5.84, the maximum petal length is 6.9, and the minimum sepal width is 2.0.

The analysis shows clear differences between the three Iris species. Setosa has the highest average sepal width, while virginica generally has larger petal measurements.

The additional visualizations also help compare the species based on sepal width, petal width, petal length, and other flower measurements.and 6.5.
